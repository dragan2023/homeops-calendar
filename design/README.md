## 二、三份的共同点（保证可比）

- 信息架构完全一致：底部 4 个 tab = 今日 / 日历 / 库存 / 待办，另有物品详情抽屉、快速录入抽屉、操作 toast。
- 数据完全一致：同一批演示物品（黄瓜明天到期、牛奶低于阈值、滤芯归零、布洛芬 10/12 过期…）、同一批待办、同一批日历事件。
- 都可真点的交互：切 tab、勾选待办、日历切日期、搜库存/按地点筛、点物品看批次、入库 +1 / 领用 -1、手动录入一条会真的进列表。
- 都满足：触控目标 ≥44px、无 emoji 当图标（全部内联 SVG）、焦点可见、支持 `prefers-reduced-motion`、底部导航不被内容遮挡。

## 三、建议按这几个维度对比

| 维度 | 看什么 |
| --- | --- |
| 一眼气质 | 打开第一屏就喜欢哪个；哪个更像"我会天天打开的 App" |
| 信息密度 | A 最疏、C 中等、B 最密；你是想"扫一眼就知道今天干什么"还是"一屏看全所有数字" |
| 临期这件事的表现力 | A 用标签文字、B 用色块角标、C 用环形进度（还剩几天一眼看到） |
| 日历 | A 是月历 + 圆点、B 是月表格里直接写事件文字、C 是"这一周"卡片条 + 小月历 |
| 录入手感 | 三份都试一下"手动填"：A 紧凑表单、B 硬边表单、C 圆角大表单 |
| 长期看会不会腻 | 极简容易显得冷、粗野容易显得吵、黏土容易显得幼稚——挑你觉得半年后还顺眼的 |
