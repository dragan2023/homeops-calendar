这一版的样子
  • 一屏能看到最多信息：容器 + 数字 + 层级都在表格里对齐，适合东西多、经常盘点的用法。
  • 日期给了「沿用上次」——同一物品重复入库时不用每次重算保质期。
  • 批量移动：勾选 → 底部栏「移动到…」→ 同一套容器清单选目标（后端一次事务里逐批调拨）。
  • 「上下移」对应数据库里已有的排序字段，容器顺序可以自己定。
