# 移动端（Expo）真机测试方案

> 参照 Life_Assistant 的做法：Expo Go 扫码、局域网直连后端、Metro 在 8081、后端在 8787。
> 应用目录：`mobile/`（独立 npm 工程，不参与根目录 pnpm workspace，避免两种包管理器打架）。

## 一、环境准备

### 1.1 开发机
```bash
node apps/api/src/server.ts     # 终端 A：后端 http://0.0.0.0:8787（DB=./data/homeops.db）
start_mobile.bat                # 终端 B：自动清 8081 上的旧 Metro，然后 expo start
```
> 后端**默认已绑 0.0.0.0**（手机连局域网必需），启动时会直接打印手机要用的地址，例如：
> ```
> 本机:      http://127.0.0.1:8787
> 局域网/手机: http://<你电脑的局域网IP>:8787   （例如 http://192.168.1.23:8787；Expo Go 会自动推导成这个地址）
> ```
> 只想本机访问就显式 `HOST=127.0.0.1`。
>
> 手机连不上时先跑自检（会指出是绑定、防火墙还是网络问题，并给出确切修复命令）：
> `node scripts/check-phone-reachable.mjs`
> 防火墙放行（管理员 PowerShell 跑一次，本机已加好这条）：
> `New-NetFirewallRule -DisplayName "HomeOps Calendar TCP 8787" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8787 -Profile Any`

### 1.2 手机
- 装 **Expo Go**（App Store / Android 应用商店 / expo.dev/go）。
- 手机和电脑连**同一个 Wi-Fi**（公司/酒店那种隔离网络的 AP 会互相看不见，必要时用手机热点）。

### 1.3 后端地址怎么来的（不用手改代码）
`mobile/src/services/api.ts` 会从 `Constants.expoConfig.hostUri` 取出 Metro 的 IP，端口换成 `app.json → expo.extra.apiPort`（默认 8787）：
- 手机加载 Metro 的那台电脑就是跑后端的那台 → 同 IP 不同端口，通常零配置即通。
- 隧道模式 / 后端在别的机器：`EXPO_PUBLIC_API_URL=http://192.168.x.x:8787 npx expo start` 覆盖。
- 登录页会把当前生效的后端地址显示出来，先看它对不对。

## 二、扫码开跑
1. 终端 B 出现二维码。
2. iOS：系统相机扫码 → 点横幅进 Expo Go。Android：Expo Go 里点「Scan QR code」。
3. 首次进入是初始化页：填家庭名 + 用户名 + 密码（≥6 位）→ 初始化并进入。
   （后端会直接签发一个家庭级 Bearer Token 存进手机 AsyncStorage —— RN 没有浏览器 cookie jar，所以不走 cookie。）

### 3.2c 容器与日期弹窗（2026-09-24 新增）
| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M-27 | 今日页「＋ 手动录入一笔」→ 点「放哪儿」那一行 | 从底部弹出容器列表：缩进显示层级、每行有「几样 · 几件」、顶部可搜索、底部「＋ 新建容器」 |

| M-29 | 点「到期日」那一行 | 弹出月历：上方快捷块（今天/明天/7 天后/30 天后/月底/不限）、当月可翻月、今天有强调色、选中日高亮 |

> 容器是层级结构（冰箱 → 冷冻室）；「停用」不删历史记录，随时可恢复。日期弹窗是自绘的，会跟着你选的 8 套主题变。

## 五、常见问题
- **Q1 扫码后白屏/闪退**：`cd mobile && npx expo start --clear`；确认 Node ≥ 20。
- **Q2 手机连不上后端（Network request failed）**：
  1) 后端是否 `HOST=0.0.0.0`；2) 手机浏览器打开 `http://<电脑IP>:8787/healthz` 应返回 JSON；
  3) Windows 防火墙放行 8787：`New-NetFirewallRule -DisplayName "HomeOps 8787" -Direction Inbound -LocalPort 8787 -Protocol TCP -Action Allow`（需管理员）；
  4) `ipconfig` 看电脑局域网 IP 是否和登录页显示的一致。
- **Q3 Android 明文 HTTP 被拦**：`app.json` 里已设 `android.usesCleartextTraffic: true`；改了 app.json 要重启 Metro（Expo Go 会重读配置）。
- **Q4 Token 失效**：后端换库/撤销 token 后会掉回登录页，重新登录即可。
- **Q5 换了主题没变**：确认点的是主题列表里的项（不是标题）；若真的异常，Expo Go 里摇一摇 → Reload。
- **Q6 扫条码相机黑屏 / 一直要权限**：先用手机系统相机确认相机本身可用；之前点过「拒绝」的话，到手机设置里给 Expo Go（或本应用）打开相机权限——App 里也会提示这条路径；改过配置要重启 Metro。

## 九、账号体系（谁建、密码是什么、忘了怎么办）

| 问题 | 事实 |
| --- | --- |
| 用户系统 | 有：`users` / `sessions` / `api_tokens` 三张表；密码 scrypt 加盐，Token 只存 SHA-256 哈希 |
| 账号从哪来 | **由第一次初始化创建**（App 首页填家庭名+用户名+密码 → 你就是管理员）；后端不预置任何账号 |
| 现在库里有什么 | 只有你自己初始化时建的 `admin`。验收脚本一律跑临时库（`data/_verify-<pid>.db`），口令来自环境变量 `SMOKE_PASS`（仓库里不存默认值），不碰真实库 —— 见 AGENTS 坑 13 |
| App 怎么知道显示哪个 | 打开时先请求公开接口 `GET /api/setup-status`：没账号→初始化表单；有账号→登录表单并显示现有账号名 |
| 忘记密码 | 电脑上双击 `set_password.bat`（输入用户名+新密码即可，不需要原密码；会同时注销旧会话） |
| 想彻底重来 | 双击 `reset_db.bat`（先把旧库备份成 `data/backup-<时间>.db` 再清空，然后重启后端 → App 回到首次初始化） |

## 十、清掉测试数据（万一列表里出现 M2-054277 这种东西）

```bash
node scripts/clean-test-data.mjs          # 预览：会改哪些名字、合并哪些重复物品
node scripts/clean-test-data.mjs --yes    # 真执行（先自动备份 data/backup-before-clean-<时间>.db）
```

- 它做两件事：①去掉物品/待办/清单/事件名里的测试前缀（`M2-054277布洛芬` → `布洛芬`）；②把同名同单位的重复物品合并成一条（批次、流水、待办、清单行全部改挂到保留的那条，重复的软删除）。
- 再狠一点：双击 `reset_db.bat`（备份+清空，回到首次初始化）→ 用你自己的账号重建一个干净的家。
- 为什么会出现：验收脚本早先跑在你的真实库上（见 AGENTS 坑 13）；现在脚本不显式指定 `BASE` 会直接拒绝运行，全链路回归 `verify-all.mjs` 自带临时库。
